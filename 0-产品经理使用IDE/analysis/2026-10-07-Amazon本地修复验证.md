# Amazon本地修复与验证

日期：2026-10-07。仅本地修改，无提交、推送、发布或oss-site全量重建。

## 修复内容

嵌入模式下完整系统框架仍渲染内部Header，导致重复面包屑、用户区和页面页签；现统一使用员工端外层导航。任务中心六个业务页签保留。

file://外层的消息来源为null，原React接收器仅接受HTTP同源消息，导致切换被拒绝；现限定父窗口来源并兼容本地文件来源。增加页面就绪握手与待发送目标，避免初始加载中的切换丢失；外层维护浏览器历史，重复点击不增加历史或页签。

方案迁至drafts/Amazon管理，与头程管理并列。与输入v2.3方案按字节比较完全一致，保留规则、分期、版本说明与10张Mermaid图。头程管理文档仅引用该方案，日期同步至10-07。对应已有HTML只移动及更新引用，未运行全量站点构建。

## 验证结果

- TypeScript类型检查、Vite构建通过。
- Chromium实际执行13组回归：四菜单连续切换两轮、选中态/面包屑/顶部页签/内容一致、单一外层顶部、重复点击、详情关闭返回、浏览器前进后退、加载中快速切换、file://跨HTTP iframe切换通过。file://验证的Vue/Element依赖由浏览器拦截加载本机同款文件。
- 任务中心六个业务页签及原查询、人工计划、批次、日志、导出、提单和Smart Reroute交互回归通过。
- 资料仓首页全部本地链接HTTP 200；新目录10张流程图实际渲染，数据设计引用的第6/21/26章锚点存在。相关Markdown引用逐一核对实际文件。
