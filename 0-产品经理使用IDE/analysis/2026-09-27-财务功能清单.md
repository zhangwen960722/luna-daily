# 财务功能清单（按模块 · 供 CTO 工作量评估）

> 用途：跟 CTO 过方案、评估工作量。
> 说明：
> - 粒度 = 功能点级（一个开发可交付的最小功能单元）；
> - 【页面】= 有交互页面；【系统自动】= 事件/定时触发、无独立页面；【后台任务】= 异步任务；
> - `(复用)` = 同一实现多处调用，工作量只算一次；
> - `归二期` / `待开发` 已单独标注，其余为本期（Phase 1）。

## 一、运单审计（财务中心 → 运单审计）

## 七、系统自动 / 后台任务（无页面，但需开发工作量）

| 功能 | 类型 | 说明 |
|------|------|------|
| 应收流水生成 | 系统自动 | 收货完成触发：运费 / 运费优惠 / 泡比优惠 / 附加费 / 附加费优惠逐行生成（优惠独立成行），跳过收货状态不生成 |
| 销售成本流水复制 | 系统自动 | 应收流水落库自动复制（费用收付类型含销售成本、非同行；同行须「同行同步销售成本」=同步） |
| 应收重算（含销售成本连带） | 系统自动 | 运单变更触发：系统自动行按去重键覆盖；未审计销售成本跟随刷新、已审计不刷新、来源应收消失未审计删/已审计留 |
| 应付流水提单平摊 | 系统自动 | 按提单实收体积分摊到运单，尾差挂最后一单 |
| 账单自动出账（应收 + 应付） | 系统自动 | 账单周期 = 固定的客户/供应商，每月 1 号跑批 |
| 超期自动确认 | 系统自动 | 账单 / 贷记单发送满 7 个自然日未确认自动确认 |
| 账龄实时计算 | 系统自动 | 未到期 + 逾期四段（应收 / 应付） |
| 金额本币折合 | 系统自动 | 金额（本币）= 金额（原币）× 汇率，前端派生展示 |
| 运单毛利计算 | 系统自动 | 毛利 = 应收折合 − 应付折合（本位币 CNY） |
| 汇率接口调用 | 系统自动 | 阿里汇率接口实时获取，币种互转留痕 |
| 账单导出文件生成 | 后台任务 | 一期演示链路；真实按财务模板逐账单出 Excel 归二期 |

## 附：你草稿里的几个疑问，对齐口径

1. **「导出」导的是什么**——分三处：
   - 运单审计主列表「导出」= 导出**运单列表**（含应收/应付/销售成本/毛利汇总）；
   - 应收/应付/销售成本**台账**「导出」= 导出**对应流水**；
   - 账单管理「导出」= 导出**账单 Excel**（走后台任务）。
2. **销售成本在运单审计里的归属**——销售成本是应收流水的复制，但**独立审计**（仅财务）；所以它在运单审计里有独立的「销售成本 Tab」+ 运单级/流水级审计，又在「提成管理 → 销售成本流水」有全量台账。
3. **新增流水的两个口径**——「直接新增」= 自由填金额/计费量；「按规则新增」= 选来源规则带出单价、自动打标（仅附加费类，含销售成本）。
4. **重算与销售成本**——订单变更重算应收时，销售成本按「未审计跟随刷新、已审计不刷新、来源消失未审删/已审留」连带处理（详见 §七表格）。
5. **舱位管理「财务信息」与运单审计的联动（★ 补漏）**——提单平摊的应付流水平摊后挂到运单，在「运单审计 → 应付 Tab」里**只读展示**（改删回舱位管理提单侧）；其审计归属是**提单审计**（提单级 + 流水级，在舱位管理做），**不走运单审计**；只有「人工添加」的应付流水才在运单审计审。另一条反向联动：运单审计「添加应付」时若填了提单号 → 挂靠同步到该提单，提单侧只读、审计仍归运单审计。
