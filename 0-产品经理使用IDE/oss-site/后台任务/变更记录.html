2026-09-16修掉查询区按钮上的 <1122> 字样（员工端 + 货主端 后台任务.html） —— 两页「查询」「重置」按钮的图标标签是纯数字占位符（早期批量脚本替换自闭合标签时留下的），数字开头的标签名属非法 HTML，浏览器解析器把它降级成纯文本，于是按钮上直接显示出这几个字符。现改为 zoom-in / refresh-right（kebab-case + 显式闭合）→ 查询显示放大镜、重置显示刷新箭头。根因与写法规范已立进 style-guide.md §原型图标写法（kebab-case 显式闭合 / 禁止自闭合 / 禁止数字占位 / 避开与 HTML·SVG 元素同名的图标）图标标签在"浏览器内联模板"里的写法会直接决定渲染结果，属可见缺陷；全仓同类问题已一并清理完毕（见本表下一条）
