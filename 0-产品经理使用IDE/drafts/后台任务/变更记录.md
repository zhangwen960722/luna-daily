| 2026-09-16 | **修掉查询区按钮上的 `<1122>` 字样（员工端 + 货主端 `后台任务.html`）** —— 两页「查询」「重置」按钮的图标标签是**纯数字占位符**（早期批量脚本替换自闭合标签时留下的），数字开头的标签名属非法 HTML，浏览器解析器把它降级成**纯文本**，于是按钮上直接显示出这几个字符。现改为 `zoom-in` / `refresh-right`（kebab-case + 显式闭合）→ 查询显示放大镜、重置显示刷新箭头。**根因与写法规范已立进 `style-guide.md` §原型图标写法**（kebab-case 显式闭合 / 禁止自闭合 / 禁止数字占位 / 避开与 HTML·SVG 元素同名的图标） | 图标标签在"浏览器内联模板"里的写法会直接决定渲染结果，属可见缺陷；全仓同类问题已一并清理完毕（见本表下一条） |
| 2026-09-16 | **全仓图标缺陷清理（118 处 / 34 个页面）** —— 把「浏览器内联模板里图标写错就渲染不出来」的 4 类问题一次清完：① **数字占位标签**（如 `<1122></1122>`）**37 处** → 换成真图标（查询 / 搜索 → `zoom-in`；按上下文另配 `connection` 销售链接前缀、`picture-filled` 图片附件、`tickets` 打款凭证、`question-filled` 截图提示）；② **多词名自闭合**（如 `<RefreshRight />`、`<InfoFilled />`）**66 处** → 改 kebab-case + 显式闭合（`<refresh-right></refresh-right>`）；③ **单词名但撞 HTML/SVG 元素**（`<View />`）**12 处** → `<component is="View"></component>`；④ **小写 `<search />`** **3 处** → `zoom-in`。修复范围含**财务流水 / 资金流水 / 资金账户管理 / 货主端菜单导航栏**等；**60 个页面全量跑 checker 通过、残留复扫 0 处**；换行风格逐文件核对未产生混合。规范与根因已写进 `style-guide.md` §原型图标写法 | 原型是「浏览器内联模板」，HTML 解析器先于 Vue 工作 —— 数字开头的标签名属非法 HTML（被降级成纯文本直接显示）、PascalCase 自闭合会被小写化（Vue 找不到组件、图标静默丢失）；这四类都会让页面上的图标变成乱字符或凭空消失 |
